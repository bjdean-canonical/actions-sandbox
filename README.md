# Brad's github actions sandbox

This documentation is a sandbox. It exists purely for testing and
experimenting.

Its contents may change, move or disappear at any time, without notice.
Some pages may be broken or incomplete, sometimes on purpose, as part of
that testing.

Even so, you are welcome to read along and take anything useful from what I
try out here. Please don't rely on it as a stable or authoritative
reference.

See: https://en.wikipedia.org/wiki/Sandbox_(software_development)
